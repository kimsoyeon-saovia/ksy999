# 상상스튜디오 제작 문의 — 이어서 작업하기

작성 기준: 2026-10-16. 이 문서는 긴 대화에서 최종 확정된 요구와 현재 구현 상태를 정리한 작업 메모입니다. 원래 대화 전체를 복제한 파일은 아닙니다.

## 학원 컴퓨터에서 시작

1. 이 ZIP을 USB나 개인 저장 공간으로 옮긴 뒤 전부 압축 해제합니다.
2. Codex에서 압축을 푼 폴더를 프로젝트로 엽니다.
3. 새 대화가 필요하면 이 문서를 읽게 하고 아래 문장을 보냅니다.

> 이 폴더의 ‘학원에서_이어가기.md’를 읽고 기존 홈페이지 작업을 이어가 주세요. 현재 디자인과 기능은 승인된 상태입니다. 먼저 실제 파일을 확인하고, 제가 새로 요청하는 부분만 수정해 주세요.

화면만 보려면 index.html을 엽니다. 이 폴더의 HTML/CSS/JavaScript는 모두 편집 가능한 원본 코드입니다. 별도 빌드나 패키지 설치가 필요하지 않습니다. 집 컴퓨터의 C: 경로를 그대로 사용하지 말고 학원에서 이 폴더가 있는 경로를 사용하세요.

## 파일 구성

- index.html: 시작 페이지. personal.html과 같은 내용입니다.
- personal.html / corporate.html: 개인·기업 문의 페이지의 기본 HTML.
- inquiry.js: 페이지 전환, 화면 구성, 선택, 수량, 상담, 모달, FAQ, 모션.
- inquiry-pricing.js: 영상 수량, 포인트와 기업 요금 계산.
- inquiry-config.js: 상품, 요금, 보너스, 상담시간, 운영 연락처, API 주소 설정.
- inquiry.css: 전체 스타일과 반응형 화면.
- assets/: 기업 이미지 4장, 영상 MP4 4개, 서울알림체 OTF 4종.

index.html의 기본 HTML을 수정해야 하면 personal.html에도 같은 변경이 필요한지 확인하세요. 실제 화면 대부분은 inquiry.js에서 구성됩니다. 배너 버튼으로 개인·기업을 전환하며, 파일 직접 실행 시 #personal / #corporate를 사용합니다.

## 유지할 디자인

- 헤더·푸터 없이 메인배너부터 시작합니다. 기존 디자인을 새로 만들거나 임의로 바꾸지 않습니다.
- 배너는 화면 전체 높이를 채웁니다. 데스크톱 버튼은 각각 394×60px, 간격 70px, 서울알림체 Medium입니다. 버튼 밑줄은 없습니다.
- 첫 진입은 개인 본문이며 배너 버튼 둘 다 미선택입니다. 버튼을 클릭하면 해당 본문 시작으로 이동합니다.
- 1920px 기준 본문 영역 1374px, 견적 영역 546px이며 본문 왼쪽 여백은 100px입니다. 모바일은 화면 폭에 맞춥니다.
- 사용 색상은 라임 #e0ff4f, 파랑 #0a47f4, 흰색, 검정, 회색 #b2b2b2, #fcfcfc를 기준으로 합니다.
- 개인 화질·길이 박스는 미선택 배경이 흰색, 선택되면 라임 강조입니다.
- 기업 이미지와 옆 설명은 하단을 맞춥니다. 기업 상품 선택 버튼은 금액 문구 너비에 맞춰 작게 만들고 우측 정렬합니다.
- 견적의 ‘예상 견적’ 제목이 금액 숫자보다 크며, ‘원’ 글자는 숫자보다 작습니다. 기업 ‘프로젝트 정보’는 입력 항목명보다 크고 진합니다.
- 개인·기업의 상담/충전 결제 버튼은 데스크톱 475×65px, 서울알림체 ExtraBold입니다. 수량·삭제 등 작은 보조 버튼은 별도 크기입니다.
- 본문과 견적서를 나누는 선은 제거했습니다. 견적서는 흰 배경과 옅은 그림자, 둥근 모서리를 사용합니다.

## 유지할 동작

- 개인은 화질과 길이를 함께 선택하면 견적서에 ‘담기’가 나타납니다. 담으면 확정 항목이 추가되고 현재 화질·길이는 해제되어 다음 영상을 고를 수 있습니다.
- 확정 영상마다 +/− 버튼으로 수량 1~999개를 조절하고, 삭제 버튼으로 항목 전체를 지웁니다. 항목 금액·필요 포인트·총 견적에 수량을 반영합니다.
- 개인 임시 요금은 (화질 포인트 + 길이 포인트) × 수량 × 10원입니다. 현재 선택 중인 영상은 중복 없이 별도로 합산합니다.
- STARTER: 50,000원, 기본 5,000c + 보너스 1,000c = 총 6,000c. PLUS: 100,000원, 기본 10,000c + 보너스 3,000c = 총 13,000c.
- 1c=10원 안내는 충전 상품 박스 아래에 있습니다. 충전 상품 비용에 지급 포인트로 충당하지 못한 영상 비용을 더합니다.
- 빈 견적으로 상담 버튼을 누르면 먼저 선택하라는 모달이 뜹니다. 개인은 확정 영상, 완성된 화질·길이 선택, 충전 상품 중 하나가 필요합니다. 기업은 제작 상품을 선택해야 하며 추가 옵션만으로는 접수되지 않습니다. 기업 ‘기타’ 상품은 유효한 선택입니다.
- 상담 필수 입력·개인정보 동의 검사가 있습니다. 성공 안내 제목은 ‘상담 신청이 완료되었습니다.’입니다.
- 성공하면 해당 개인/기업의 선택, 담은 영상·수량, 충전 상품, 추가 옵션, 입력 내용과 동의가 초기화되고 0원으로 돌아옵니다. 본문 선택 표시도 해제됩니다. 실패하면 작성 내용을 유지합니다. 다른 페이지에서 작성한 내용은 지우지 않습니다.
- FAQ는 다른 페이지에 갔다 돌아오면 닫힙니다. 개인·기업 페이지를 전환하면 떠난 페이지의 견적 선택·영상 수량·충전·옵션·입력·동의를 모두 초기화합니다. 다시 돌아오면 빈 견적입니다. 성공 때도 초기화합니다. 같은 페이지의 배너 버튼을 다시 누르는 경우에는 본문으로 이동하며 입력을 유지합니다.
- 카카오톡은 채널 안내, 이메일은 같은 크기와 스타일의 카카오/네이버/구글 선택, 전화는 가상 번호 02-0000-0000 연결 확인창을 사용합니다.
- 한국 시간 평일 10:00~19:00 밖에는 ‘지금은 상담 안내 시간이 아닙니다.’를 표시합니다.
- 개인정보 내용보기와 결제수단·금액 확인 모달이 있습니다. 체크박스와 버튼은 손가락 커서, 입력칸은 텍스트 커서입니다.

## 유지할 모션

- 배너 제목과 부제 두 줄 모두 아래에서 위로 순서대로 등장합니다. 양옆에서 들어오는 효과는 없습니다.
- 배너 버튼은 등장 모션 없이 마우스를 올릴 때만 살짝 확대됩니다.
- 기업 이미지·설명, 개인 금액 박스, 본문 제목·상담 버튼·FAQ 행도 화면에 들어올 때 부드럽게 아래에서 위로 나타납니다.
- 기업 이미지 4장은 마우스 오버 시 1.035배 확대되고 옅은 그림자가 생깁니다.
- 기업 사진의 오른쪽 아래 손가락 아이콘과 ‘클릭해서 재생’을 눌러 해당 위치에서 영상이 무음으로 한 번 재생됩니다. 종료하면 원래 사진과 아이콘으로 복귀하고, 다시 클릭하면 재생합니다. 반복 자동 재생은 없습니다. 재생 중 중복 클릭은 무시하며, 다른 영상을 누르거나 페이지·탭을 떠나면 이전 재생을 멈춥니다.
- 영상은 받은 파일 순서 1→AI 숏폼(shorts.mp4), 2→브랜드 영상(brand.mp4), 3→AI 캠페인(campaign.mp4), 4→기타(custom.mp4)입니다. 원본 PNG는 기본 사진으로 유지합니다. 미리보기 클릭과 상품 선택은 별도 동작입니다.
- AI 숏폼의 기본 사진 shorts.png는 이후 받은 1.png(하늘을 나는 빨간 망토의 치킨)로 교체했습니다. 첫 표시와 영상 종료 후 복귀에 같은 파일을 사용합니다.
- 견적서는 데스크톱 상단 80px 위치를 따라오며, 스크롤 시 작은 탄성으로 움직입니다. 입력하거나 견적서를 클릭할 때는 멈춥니다. 모바일은 정적으로 배치합니다.
- 견적 높이가 화면보다 길면 견적서 안에서 스크롤합니다. 아래로 스크롤하면 TOP 버튼이 나타납니다.
- 움직임 줄이기가 설정된 미리보기에서도 짧고 작은 상향 효과가 보이도록 JavaScript 효과가 있습니다. 효과 종료 후 글자 변형을 제거합니다.

## 아직 실제 운영과 연결되지 않은 부분

inquiry-config.js의 inquiryEndpoint와 contacts가 비어 있습니다. 현재 성공 안내는 화면 확인용이며 실제 상담 전송은 하지 않습니다. 실제 결제도 연결되지 않았고, 결제수단·금액 확인까지의 화면입니다. 가상 전화는 실제로 발신하지 않습니다. 운영 연결 전에는 이 상태를 실제 접수·결제로 설명하지 마세요.
